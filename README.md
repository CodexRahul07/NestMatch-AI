# 🏠 NestMatch AI – AI Powered Roommate Finder
NestMatch AI is a full-stack roommate matching platform built using the MERN Stack and Google Gemini AI. The application helps users discover compatible roommates based on lifestyle preferences, location, and personal requirements with AI-powered compatibility insights.

---
## 🚀 Features
🔐 Secure User Authentication using JWT
👤 User Registration & Profile Management
🤖 AI-Based Roommate Compatibility Matching
✨ Google Gemini AI Match Explanations
📊 Preference-Based Matching Algorithm
🎨 Responsive UI built with Tailwind CSS
🌐 RESTful API Integration
🗄️ MongoDB Database Management
